Language of Thought (LoT) Sequence Complexity Framework

Oct 2025 – Mar 2026

Python

A minimal formal language for generating sequences. The goal is to find the smallest program that produces a given sequence — a computable analogue of Kolmogorov complexity.

  • Implemented the LoT instruction set: play, move & play, and three loop constructs — fixed repetition, iterative mapping and iterative evaluation.
  • Implemented direct generation of a string sequence from a given program, and defined and implemented the computation of program space complexity.
  • Implemented a dynamic-programming search that returns, for every substring and start position, the minimal program and its complexity; analysed and reduced the running time to polynomial.
  • Refactored the complexities_and_minprog, exe and size modules to decouple complexity computation, execution and parameter configuration; designed an indentation-based LoT syntax and parser.

rgbds-live: improvements to an online programming interface

May 2026 – Jun 2026

Node.js · JavaScript · npm · Vite

Open-source contribution to rgbds-live, the browser IDE used for Game Boy assembly in the Digital Systems course.

  • Built and published an npm command-line tool that serves a local Game Boy assembly project over a local HTTP server and opens it in the web IDE, bypassing the 2 KB URL-hash project size limit while keeping every file on the user's own machine.
  • Supported opening remote URLs and local files directly from the terminal, streamlining the edit–compile–test loop.
  • Rewrote the assembly log parser so compiler diagnostics carry file and line metadata, enabling one-click navigation from an error message to its source location.
